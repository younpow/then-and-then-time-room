# THEN AND THEN — THE THICKNESS OF TIME

**YOUN SUNGMIN · 2026**  
Interactive photographic artwork · Exhibition Edition **v1.3.1**

A room, photographed fourteen times. Visitors choose which moments coexist and move their viewpoint to discover time held in overlapping, sliced, and depth-shifted spatial views. Image and sound respond to these choices in real time.

## Experience the work

Open the published GitHub Pages link in a modern browser. Press **ENTER THE ROOM**, and use **VIEW**, **CHOOSE MOMENTS**, and **WATCH** to interact. Turn on sound when desired. Headphones recommended.

The standalone `index.html` contains the photographic assets and visual/sound code; no external content files are required. The site is intended to be served via HTTPS through GitHub Pages.

## Release notes

- Final exhibition baseline: **v1.3.1**.
